# 管理工作区布局

`ManagementWorkspace` 是静态管理页中“选择区 / 树 / 列表 + 右侧主体”的轻量布局契约。它负责列轨道、响应式边界和编辑期间的导航互斥；数据加载、选择联动、表单和动作仍由页面及现有 `RecordExplorerPanel`、`RecordDetailPanel` 负责。

## 稳定尺寸

| 语义         |  默认值 | 说明                                                           |
| ------------ | ------: | -------------------------------------------------------------- |
| 选择区列宽   | `280px` | 租户、分类、岗位等 explorer/tree/list 区使用同一列宽。         |
| 主体最小宽度 | `560px` | 详情、编辑表单和操作区的共同下限，避免双列表单控件被压出面板。 |
| 列间距       |  `12px` | 多栏管理页的统一间距。                                         |

布局以 `explorerCount` 声明选择区数量：一栏对应“选择区 + 主体”，两栏对应“树 + 列表 + 主体”，三栏对应“租户 + 树 + 列表 + 主体”。页面可以通过同名 CSS 变量做有依据的局部调整，但不应在业务页重新定义列栅格。

## 宽度与响应式规则

普通管理工作区默认优先保证右侧主体：根据宿主实际宽度，从左到右自动收起声明为 `collapsible` 的导航选择区，保留统一的折叠栏。详情主体优先保留 `560px`，纯列表主体优先保留 `720px`；所有可折叠导航收起后仍不足时，主体使用剩余宽度，宽表在面板内部滚动。

自动收起不更改选择和手动折叠状态；宿主变宽后只自动还原因空间不足收起的导航。窄宿主中点击折叠栏打开浮层预览，不挤压主体；空间充足时点击还原整栏。预览可按 Escape 关闭，继续沿用导航编辑锁。

桌面端工作区以工作台内容区的 `100%` 为高度基准，不重复估算顶栏和页签高度，避免外层出现几像素的空白滚动。`ManagementExplorerColumn` 表达选择区语义，并拉伸到该可用高度；各 explorer 继续在自身内容区滚动。右侧详情或编辑卡片保持按实际内容占高，不因选择区而被拉伸。内容超过视口时，工作区自然增高，不截断详情或编辑内容。

带独立常驻详情面的工作区仍复用列表与详情的宽度预算及既有抽屉提升规则。不可折叠的业务选择区保留其布局契约；`composer` 使用独立的位置编排，不参与自动折叠。

`listSurface` 不含常驻详情面，主要承载“导航 explorer + 列表”场景。声明可折叠导航时沿用同一自动折叠策略；没有可折叠导航的存量工作区保留窄屏上下编排。字段表单的单列降级仍由各页面或字段组件按自身语义控制。

## 使用边界

```vue
<ManagementWorkspace :explorer-count="2">
  <ManagementExplorerColumn>
    <RecordExplorerPanel title="分类">…</RecordExplorerPanel>
  </ManagementExplorerColumn>
  <ManagementExplorerColumn>
    <RecordExplorerPanel title="岗位">…</RecordExplorerPanel>
  </ManagementExplorerColumn>
  <RecordDetailPanel>…</RecordDetailPanel>
</ManagementWorkspace>
```

岗位管理是首个基准页面：租户系统用户使用三选择区，租户及以下用户使用两选择区。两栏的 `StaticManagementLayout` 同时复用这套契约；其余已有页面在调整布局时迁移，避免为了视觉统一而改变其业务交互。

## 编辑期间的导航互斥

工作区通过 `editing` 声明右侧正在新建或编辑。`ManagementExplorerColumn` 与工作区列表自动进入禁用状态，统一阻止选择、搜索、刷新、分页、拖拽和键盘聚焦；业务不逐项绑定禁用属性。保存期间及失败后保持编辑状态，取消或保存成功后恢复。排序是独立操作，不开启此编辑锁。排序开关位于所属导航面板，拖拽即时保存，无需额外确认；请求期间阻止重复拖拽，写入失败恢复已保存顺序并提示原因；写入成功但回读失败时保留已提交顺序，提示用户刷新重试同步。排序开关不隐藏或禁用详情动作；只有实际排序请求期间，工作区统一锁定导航与详情交互，请求结束后恢复。通用树、列表向所属工作区报告请求状态，独立工作区互不影响。进入编辑后使用原有编辑锁暂停拖拽。元数据树排序包含系统字段及子实体关联字段，只更新展示顺序，不改变字段定义、实体关系或物理表结构；隐藏系统字段时保留其排序位置。字段定义保护与展示排序权限独立。排序保存后仅同步受影响的字段或关系记录，不重新加载整个工作区；保留树组件、滚动位置、展开状态和选中项。新增、修改、删除后的同范围刷新同样保留现有节点，数据就绪后更新；仅首次加载或切换数据范围时清空视图。删除选中节点时回退到仍存在的父节点或可用节点。

`StaticManagementLayout` 和标准模块运行器自动传递编辑状态；专用工作区只绑定同一 `editing` 属性。状态只作用于当前工作区，独立工作区不互相锁定。`RecordDetailPanel` 内的子表和编辑控件属于当前编辑内容，不继承外侧导航锁。路由离开与页签关闭仍使用工作台未保存保护。
