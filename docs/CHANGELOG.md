# 变更记录

本文件记录面向 MuYunSpring 使用者的正式发布内容：新增能力、行为变化、兼容性影响和迁移要求。

## Unreleased

## 0.26.17 - 2026-10-19

### Added

- 交付动静共用的业务内容多语言能力，覆盖主子表原文来源、修订历史、独立阅读偏好、持久化机器译文及受权人工维护。
- 支持原文与有效译文的检索、服务端排序分页、引用及树形阅读，贯通既有流程办理意见与历史核实。
- 支持业务填写、阅读导出与译文草稿 Excel 文件，提供名称解析、部分成功回执和失败文件修正重传。
- 新增质量协作业务样板及可信身份下的持久化翻译任务、有限重试、租约恢复和受控补齐入口。

### Changed

- 审批流程配置复用公共管理布局、表单及字体规范；工作台统一当前页标题刷新、账号菜单、语言与皮肤设置和有序均衡菜单布局。
- “左树右卡片”的左侧统一作为完整导航，内部沿授权查询协议分批读取，取消分页交互及标题数量展示。
- AI 助手入口按当前认证身份的有效模型配置、启用供应商及可解析凭据决定可用性；身份切换撤销旧状态，实际调用仍由后端重新校验路由。

### Fixed

- 修复业务译文迟到响应、旧原文修订、权限与执行范围变化时的状态串用，保持原文、译文和人工确认的独立授权边界。
- 修复文件主子表可见范围、引用草稿核对、事务回执及动态建表竞争，减少导出的重复详情读取。
- 修复审批流程组织作用域加载、创建恢复及管理界面布局问题，统一工作台按钮高度、悬停、键盘聚焦及窄屏表现。

### Compatibility

- 业务内容多语言覆盖租户内协作，语言不扩大访问资格；原文、引用 ID、字典 code、公式和所属业务的事务及权限契约保持稳定。业务译文不随应用配置包复制。
- AI 助手宿主接入需提供与当前身份对应的后端可用性判定；仅提供请求函数不再显示入口。配置可用性不代表模型供应商网络健康。
- 当前多语言交付适用于受控小范围试用，实际业务语义审阅和生产容量仍需由使用方确认；千行业务文件上限不是交互时延承诺。大型数据检索应使用标准表格页面。

## 0.26.16 - 2026-10-16

### Added

- 交付动静统一审批配置与业务任务链路，覆盖流程画布、定义发布、任务检查、办理身份、转办加签、工作台及运维恢复。
- 平台与标准填报界面支持中英文，提供统一语言目录、账户偏好、代码资源和在线配置译文独立发布；语言切换保留草稿、查询条件和业务上下文。
- 在线配置、预置菜单与角色、引用候选及共享展示入口保留文本来源，支持按语言展示；流程实例与历史按冻结的原文身份和版本解析译文。

### Changed

- 统一审批动作授权、业务写入、任务执行和实时变更通知，复用租户、数据范围、生命周期及权限契约。
- 用户可达的领域拒绝保留原始错误事实与文本来源，在页面、流程结果和导入错误行中按消费者语言展示。
- 消费包内置页面与公共组件统一使用宿主 API 地址、认证会话和请求上下文，支持认证恢复及流式请求；独立消费者验证覆盖真实构建产物。

### Fixed

- 修复动态导出跨动静引用标题读取及静态详情、表单引用摘要缺失，保持引用身份与原始业务值。
- 修复字典候选与保存校验的租户边界、配置译文补读作用域、回收站来源读取及标准表格展示资源遗漏。
- 修复流程办理预览、版本、终态恢复及桌面布局问题，收敛页面刷新和在线状态事件的身份与范围边界。
- 修复语言切换时的迟到响应、确认提示与历史会话文案来源，以及助手选择续办丢失原始业务目标的问题。

### Compatibility

- 业务记录仍保存原始填写内容；界面译文不写回业务字段，字典 code、引用 ID、技术表头及既有数据交换语义保持稳定。本版本不交付业务内容自动翻译或多语言填报版本维护。
- 默认正式交付中英文；法语资源用于扩展验收，不代表完整法语交付。

## 0.26.15 - 2026-10-07

### Added

- 人工与智能助手共享元数据、规则、受模板约束的页面编排和模块菜单治理会话，支持多模块候选、对话内审阅确认、提交结果核实与安全续接。
- 标准主记录与一层聚合明细支持助手填报、引用选择回填、计算预览、草稿核对与放弃；复用人工页面的权限、范围、字段约束和保存回执。
- 新增会话历史持久化与受控恢复、供应商 token 和回合用量诊断、reasoning 配置；能力目录按当前作用域按需加载并有界复用。
- 动静字段共用规范化与阶段必填规则；普通字段和字典固定默认值通过标准变更集发布，并按最终类型、容量、精度、正则及字典选项校验。
- 开启交换能力的动态模块新增标准导入与当前查询导出入口，支持解析核对、确认执行、结果统计及可修正重传的主子表错误文件。

### Changed

- 统一业务标准写入的事务、租户与数据范围门禁、生命周期、引用读取和缓存依赖维护；服务必需依赖在构造时完整声明，业务接入不再复制平台流程。
- 标准列表查询、分页和导出复用服务端查询契约；文件绑定统一所有权与图片事实，模块菜单治理复用共享平台配置会话。
- 模块字段覆盖仅保存本层声明，继续继承基础配置；绑定和初值版本分别校验，共享字段演进同时检查基础、其他关系及旧配置。确认指纹只保护实际依赖。
- 升级 MuYunDatabase 至 3.26.22，并校准租户索引及 schema 契约；同步升级构建工具和相关依赖。

### Fixed

- 修复候选变化、页面切换、身份或范围变化时的迟到执行；区分写前拒绝、已提交但界面同步失败和结果未知，避免重复写入或错误认定成功。
- 修复默认值继承固化、字段改型遗漏其他模块初值与字典类型约束，以及 PostgreSQL JSON 参数绑定和记录读回类型语义。
- 修复导入同名展示字段的身份判定、公式与子表字段依赖保护、引用回填类型约束、人工未解析输入保留及菜单方案切换竞态。
- 修复局域网 HTTP 缺少原生 UUID 方法时的保存失败，人工和助手操作均使用安全随机请求标识。

### Removed

- 移除 construction 专属的初始化、字段、页面和菜单写路径，调用方应迁移至标准治理；历史回执保留只读查询。
- 收敛旧服务基类与缺依赖构造兼容入口，手工装配应补齐现行构造依赖；动态 JSON 字段按实际 JSON 值交付，客户端不再自行编码存储文本。

## 0.26.14 - 2026-09-22

### Added

- 新增平台智能助手标准交互链路，覆盖流式回合、澄清续接、结构化选择、标准列表查询、表单填报和元数据字段候选编排。
- 新增助手页面范式知识、引用与字典字段解析、跨页面阶段执行及运行诊断，使平台能力可通过稳定页面契约被助手调用。
- 业务日志新增运行期留存策略、即时清理和查询页面内嵌治理入口，并统一留存任务的调度、并发与安全边界。

### Changed

- 收敛助手语义、页面令牌、会话生命周期和执行结果反馈，空白响应、失效页面和过期异步结果统一按失败关闭处理。
- Gradle、前端 manifest 与 lockfile 统一使用同一个 `X.Y.Z-SNAPSHOT` 开发版本；正式 Tag 发布后自动推进下一开发版本，跨年时从新年份的流水号 1 开始。
- 本地 Maven 依赖供应与 Maven Central 正式发布解耦：本地消费者仓库不再要求签名材料，Central staging 和上传继续强制签名及凭据校验。

### Fixed

- 修复智能助手跨页会话、引用文本回填、元数据预检和澄清后目标延续等边界问题。
- 修复日志留存策略保存与即时清理耦合、操作入口分散及列表标题被治理控件覆盖的问题。

## 0.26.13 - 2026-09-21

### Added

- 新增统一业务日志治理与运行日志查看能力，覆盖业务活动、登录审计、请求错误、页面访问统计、操作用户范围筛选和实时日志流。
- 新增平台智能模型供应商、分层配置、路由解析、连接诊断和 OpenAI 兼容客户端，为业务侧提供统一模型调用门面。
- 新增统一引用选择与只读浏览组件，覆盖对象、用户、职员、字典、树形范围及标准模块详情浏览，并复用引用授权和数据范围契约。
- 标准模块页面宿主新增统一租户作用域，系统身份可选择授权租户，租户身份自动固定登录租户；查询、引用、动作和主子表写入共享同一页面租户会话。

### Changed

- 收敛标准查询 DSL 与运行时契约，支持组合条件、引用值编辑、常驻查询控件和统一查询 schema；日志检索及动态查询复用同一治理边界。
- 模块页面运行时拆分为页面生命周期控制、业务会话和稳定渲染宿主，租户切换或重新加载时隔离旧响应，并保留页面布局与导航状态。
- 字典字段支持下拉、单选等多形态展示；模块引用详情统一使用标准详情投影、授权动作和异步交互保护。
- 角色授权范围、用户和职员候选选择统一接入标准树、列表与引用投影，减少治理页面的专用实现。

### Fixed

- 修复业务租户请求校验器未进入标准装配链路的问题，并补充完整应用上下文回归验证。
- 修复租户页面首次加载失败后的恢复入口与重试绑定；固定登录租户不再在下游导航副标题重复展示，同时保留上游业务范围提示。
- 修复智能模型配置保存、入口、租户边界和表单动作契约，以及模块引用抽屉的交互状态与并发动作保护。

## 0.26.11 - 2026-08-28

### Added

- 标准列表页面支持声明式查询摘要：`MATCHED_COUNT` 直接复用完整查询命中数，业务摘要通过受当前查询、租户和数据范围保护的 `ListQuerySummaryContributor` 扩展；动态 `LIST_DETAIL_CARD` layout 也可声明同一摘要模型，标准查询响应以 `summaries` 返回结果。contributor 以 `(moduleAlias, contributorKey)` 注册为唯一 catalog，重复、缺失配置会在启动、静态计划编译或动态发布候选计划阶段失败。

### Changed

- 常驻查询控件归入页面 UI 状态 DSL：控件值通过标准 `externalQueryValues` 立即重查，服务端查询描述符仍是过滤语义、授权和数据范围的唯一所有者。
- 动态模块不再提供独立列表摘要查询入口，列表数据与摘要统一由 `POST /{moduleAlias}/query` 在同一有效查询范围内返回。
- 统一详情会话的取消去向：列表发起的新建或编辑取消后关闭；详情内编辑及树形持久详情卡取消后恢复浏览态。
- 页面 DSL 按关系持久化语义声明关联明细，并显式区分列表过滤、表单预填和写入约束；页面操作与展示 traits 分别归入独立作用域。动态页面 layout 统一经版本化根节点契约解析和发布校验。

### Fixed

- 修复详情抽屉关闭后再次编辑无法重开，以及新建取消意外恢复列表选中记录的问题。

### Removed

- 移除已由语义化 DSL 门面替代的旧关系、导航与 traits API；静态页面声明应使用 `relation(...)`、显式 context binding、`operations(...)` 和 `presentation(...)`。
- 移除已由统一命名、目标不可用引用完整性、角色用途、附件生命周期和标准读投影替代的兼容 API。当前未有业务项目依赖这些 jar 包。

## 0.26.9 - 2026-08-24

### Changed

- 页面 navigator 的 `management` 收敛为默认关闭的二元开关：声明后提供来源模块完整的标准新建、编辑、删除能力，并继续受来源模块的动作授权、数据范围和记录可用性约束。历史动态布局中的 `management.actions` 会被读取但不再保留动作子集语义；升级后应复核原先只配置部分操作的导航页。

## 0.26.8 - 2026-08-17

### Added

- 平台新增在线实时业务提醒：业务服务可按全局、租户、机构、部门、岗位或人员范围发布通知，前端工作台统一展示并支持导航和业务命令动作。

### Changed

- 业务提醒的领域契约收敛到平台层，IAM 负责收件人身份范围解析，Web 层只承担在线投递与安全投影；提醒动作继续通过业务服务重新校验权限、数据范围、状态和幂等性。

## 0.26.6 - 2026-08-11

### Added

- 动态模块页面运行器支持范围微列表工作区、树形范围选择和受控模块页面增强。
- 标准模块页面新增轻量列表刷新门面，HTTP 层支持 SSE 流式响应与显式异步请求上下文。
- 完善文件引用表单运行时：支持上传、移除、附件字段与记录附件的统一保存生命周期，以及文件大小展示。
- IAM 租户管理员授权接入平台授权动作，并统一其权限语义。

### Changed

- 收敛模块页面展示、菜单入口 bootstrap、应用壳层和品牌菜单控制等前端运行时边界。
- 静态与动态页面复用统一的字段展示、选项回填和受控交互语义。

### Fixed

- 修复禁用模块动作、树模块列表刷新、工作台路由与页签同步、文件保存失败及失效历史引用更新等边界行为。
- 修正菜单切换悬停抑制和附件移除交互，避免多余保存提示。

## 0.26.5 - 2026-08-07

### Fixed

- 标准模块详情抽屉在完整详情读取成功前保持加载态，失败时可重试，避免以列表投影直接编辑或保存。
- npm 消费者验证改为隔离安装刚生成的 tarball，避免复用 registry 中同版本包造成假阳性。
- `RecordModeDrawer` 承担标准编辑与保存动作，保持模块运行器不直接依赖 UI adapter。

### Changed

- 面向业务 App 的示例只使用 `@ximatai/muyun-web-app` 公开组合包；内部 `@muyun/*` 目录不再被表述为当前消费者依赖。

## 0.26.4 - 2026-08-06

### Fixed

- 修复 `@ximatai/muyun-web-app` 的发布声明引用内部 alias、管理型 App 路由误捕获与动态运行器 UI adapter 边界问题。

### Changed

- `gradle.properties` 的 `muyunVersion` 成为前端 npm 包版本的一致性来源；打包时自动校验两者对齐。

## 0.26.3 - 2026-08-06

### Changed

- 首发 `@ximatai/muyun-web-app@0.26.3`：面向管理型 App 交付工作台、标准模块运行器、平台管理页与完整 TypeScript 类型声明。
- 发布前以本地 Maven 坐标启动独立消费者；Maven Central 真实坐标验证保留为首发或发布链路调整后的人工检查。
- Release workflow 将消费者预检、发布工作区清理和 Maven Central 上传分阶段执行，保证上传只使用本次构建的构件。

### Removed

- 不再在 `local` profile 启动时自动升级 pre-FieldSpec 字段目录 schema；升级前须在应用停机后执行
  `scripts/migrations/field-catalog-pre-fieldspec-postgresql.sql`。

## 0.26.1 - 2026-08-05

### Added

- `muyun-spring-bom`：统一公共平台 artifact 的依赖版本。
- `muyun-spring-boot-starter`：标准 Spring Boot 自动装配入口，业务应用无需依赖 `muyun-boot`。
- Maven Central 发布任务、签名校验、tag gate 和本地消费者仓库验证。

### Changed

- `muyun-boot` 收敛为框架自身的本地运行宿主；平台装配迁移至公共 Starter。
