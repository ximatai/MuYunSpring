# 变更记录

本文件记录面向 MuYunSpring 使用者的正式发布内容：新增能力、行为变化、兼容性影响和迁移要求。

## Unreleased

### Added

- 新增通讯录同步阶段 B：整轮成功后的有界缺失判定、可信离职及本租户会话撤销、调岗与来源默认授权回收、同步根影响预览及管理员确认、来源状态最大年龄（默认24小时）与登录前权威刷新；管理端标准解绑同时撤销会话并阻止同步自动重绑，保留本地启停及手工任岗、授权。

- 新增通讯录同步阶段 A：厂商无关分页读取协议、开发模式可编辑模拟通讯录、多根机构映射、只读预览、幂等开户与多部门任岗、租户托管同步计划及只读运行记录。任岗新增来源标记，来源状态与本地启停分离；同步游标与逐轮身份事实支持接管及人工续跑。新增过期外部登录事务的有界平台作业清理。缺失、离职会话撤销与调岗回收由阶段 B 补齐。

- 新增定时动作计划与系统身份定时调用白名单管理：静态领域显式贡献、动态模块动作元数据声明后，可按计划调用无需记录或表单的模块动作，复用动作授权、数据范围、生命周期与运行审计。支持最后修改人身份及受平台白名单控制的系统身份，运行冻结输入、执行时重新验证账号、权限与目标状态，失败通知范围管理员及发起人。

- 新增平台后台作业核心机制：持久计划与运行、数据库租约与集群互斥、秒级队列、重试与取消、受租约保护的业务事务、管理员失败提醒及有界运行留存。新增 `platform_job_plan`、`platform_job_run` 两张表；严格 schema 模式升级前需按平台 schema 迁移流程建表及索引。
- 新增 `muyun.platform.job.*` 配置（自动调度开关、扫描间隔、通道线程数与领取间隔、租约、停机宽限和留存天数），自动调度默认开启；运行运维新增作业计划和作业运行管理模块，支持立即执行、暂停、恢复、取消及失败重试，租户管理员仅能管理本租户。
- 新增租户内系统执行主体：保持租户过滤及既有 `isSystem()` 语义，运行审计记录后台作业操作者、系统原因和作业关联标识。

- 公开 `TenantScopeExplorer` 与 `ManagementExplorerColumn`，供自定义业务页复用平台租户列表和可折叠导航；补充只依赖公开包的执行租户示例及安装包消费者契约，保留普通用户固定租户、请求范围隔离和迟到响应防护。
- 账号连续登录失败达到阈值后锁定，锁定期内不校验密码、对外统一返回认证失败；默认 5 次失败锁定 15 分钟，可通过 `muyun.iam.login.lockout.max-failed-attempts`（0 表示关闭）与 `muyun.iam.login.lockout.lock-duration` 配置。修改本人密码时的当前密码校验同样受锁定约束并计入失败次数；管理员设置或重置密码会解除锁定。
- 账号支持无本地密码状态（`passwordStatus=none`），此类账号不能使用密码登录；会话与登录审计记录登录方式。
- 机构新增可选的字典字段“机构类型”（`iam.organization_type`），平台预置公司、分支机构、事业部，租户可在本租户字典中扩展。
- 新增 `@AnonymousEndpoint`，用于显式声明不属于平台动作、允许匿名访问的单个 HTTP 方法。
- 新增可选开启的外部身份登录与绑定（`muyun.iam.federation.*`，默认关闭）：平台超级管理员维护外部身份源（含协议配置），租户配置外部登录方式；锁定租户的登录页提供扫码登录入口，用户可在个人信息中绑定和解绑外部账号。身份源回调到工作台，只有发起登录的浏览器能凭本地保存的 state 与一次性凭证完成登录或绑定；每个事务附带只存于服务端的 PKCE 校验串，泄露的授权码不能移植到他人的事务。身份源协议以 `ExternalLoginProtocol` 插件接入，插件只收到只读的 `IdentityProviderDescriptor`，可声明决定身份范围的协议配置项，身份源已有绑定时这些配置与协议类型、Client ID 一并锁定；开发模式提供模拟身份源用于联调。外部登录会话的登录方式记为 `external:<身份源编码>`，不受密码登录锁定影响。

### Changed

- 通讯录协议校准为部门人员分页直接返回资料，按本轮任职观测聚合后逐人写入主岗与兼岗，支持无主部门时稳定推定并记录来源；部门祖先改由平台有界回溯，员工详情成为超龄登录核验的可选能力。仅明确声明单企业内部应用的登录协议允许从身份源配置补齐缺失企业标识。同步事实及任岗表新增聚合资料和主部门来源字段，未上线阶段直接更新协议与 schema。

- 业务内容翻译生成迁入平台排队作业，新增自动装配的 `content-generation` 通道；原 `muyun.content.generation-workers`、`generation-delay-ms` 分别映射为线程数、领取间隔，范围与默认值不变；`generation-initial-delay-ms` 保留首次延迟，从应用就绪后起算。每路继续在执行结束后等待间隔。可使用通道 `threads`／`claim-interval` 配置，显式新旧值冲突时启动失败，内容线程数仍限 1–8。五分钟租约、三次尝试及 15／30 秒退避、原触发者恢复、权限额度和 30 天留存保持不变，禁止管理员人工重试以替换触发者。
- `platform_business_content_generation` 新增可空 `run_id varchar(32)`（历史终态可无关联运行），移除 `attempts`、`available_at`、`lease_token`、`lease_until` 及其领取索引；专题仍保存业务状态及问题码。终态生成记录清理改为每小时的平台级定时作业，运行记录独立保留 30 天，原文、译文与证据不随之删除。关联运行先到期时终态状态仍可查询，已清理的尝试明细返回 0。
- 交换文件清理迁入平台作业机制，保持每小时 fixed-delay、首次延迟一分钟、每轮最多 10×200 条；日志留存清理和工作流超期扫描也改由平台级作业在 `default` 通道承担，获得集群互斥、运行记录和失败治理。人工日志清理、存储锁、业务留存策略、批次上限及超期判定保持不变。
- 保留日志留存 `scheduled-enabled` 与全局作业调度开关；日志留存 `scan-delay`/`initial-delay` 和工作流 `overtime-scan-delay-ms`/`overtime-scan-initial-delay-ms` 用于首次登记 fixed-delay 计划，默认值保持不变。已登记计划以持久配置为准，后续调整通过作业管理页完成，部署重启不覆盖管理员修改；固定间隔统一受平台至少一分钟的计划校验约束。在线闲置检测保持节点本地执行。

- 业务提醒保留单卡片外观，统一为最新可处理提醒在左上方的右下堆叠；右下铃铛统一承接数量及卡片展开、收起，展开后直接排列独立卡片，不增加面板外框；展开、收起使用逐张移位过渡并遵循减少动态效果设置；铃铛提示本次页面提醒刷新后清空。关闭卡片仅移出本次展示，不代表业务处理；重复推送去重，过期、撤回及业务明确完成时同步更新集合与数量，不增加消息持久化或历史能力。

### Fixed

- 通讯录同步支持按模式及范围版本去重、按策略时区调度，并有界清理超过 30 天的旧专题事实，保留最近整轮正式同步与其后运行。

- 标准模块从抽屉内继续打开引用详情时，不再先打开加载占位抽屉再替换为目标抽屉，避免闪烁及重复滑入；普通只读引用的加载提示和引用失败展示保持原有行为。
- 管理导航的手动展开和收起优先于自动宽度策略，并在当前页面会话内保持；手动展开恢复标准并排布局，支持多个导航同时展开，宽度不足时通过最小宽度和横向滚动承接，不再使用浮层。

### Compatibility

- 未声明平台动作且未标注 `@AnonymousEndpoint` 的 HTTP 入口改为默认要求登录，不再对匿名请求静默放行。二开应用中确需匿名访问的接口（如外部回调）须在对应方法上标注 `@AnonymousEndpoint`；属于平台动作的入口继续使用 `ActionAccessMode.ANONYMOUS_ALLOWED`，两者不能同时声明。Spring 错误控制器只在容器错误派发时免登录，直接请求其方法同样要求登录。
- `iam_user.password_hash` 改为可空，`iam_user_session` 新增 `authentication_method`，`iam_organization` 新增 `organization_type`。开发态 schema 自动迁移；严格迁移模式不会自动放宽非空约束，升级已有库需先执行 `ALTER TABLE iam_user ALTER COLUMN password_hash DROP NOT NULL`。
- `UserSessionView` 在 `passwordChangeRequired` 之后新增 `authenticationMethod` 组件，直接调用其构造器的代码需要补充参数；`PasswordStatus` 新增 `NONE`，按状态穷举处理的代码需要覆盖该值。
- `TenantLoginContext` 新增 `externalLoginMethods` 组件（元素为 `TenantLoginMethod`），`/iam.auth/login-context` 响应相应新增该字段；直接调用其三参构造器的代码需要补充参数，原两参构造器保留。前端 `@muyun/web-core` 新增 `createExternalLoginClient` 与相关类型，`LoginView` 新增可选的 `externalLoginClient` 属性；自建工作台外壳如需支持外部登录，应在身份源回到工作台根地址时调用该客户端完成事务。

## 0.26.23 - 2026-10-23

### Added

- 前端提供 `@ximatai/muyun-web-app/record-read` 子路径，在不加载 UI 和工作台注册的情况下消费记录读取会话及具名入口解析，支持 Vue effect scope 与 Node 测试；原根入口保持兼容。

### Compatibility

- 明确 Spring Boot 4 消费应用须设置 `spring.http.converters.preferred-json-mapper=jackson2`，使两代 Jackson 共存时实际 HTTP 转换器采用平台 JSON 模块；可在消费验证后移除重复的 Jackson 3 依赖排除。该约束不表示平台已迁移 Jackson 3。

## 0.26.22 - 2026-10-23

### Added

- 标准关联详情支持仅凭目标模块和记录 ID 独立打开带必选导航范围的记录，由服务端从已授权的持久化记录解析必要上下文；静态与动态模块共用范围策略，业务无需补查组织或拼装导航参数。

### Changed

- 明确 Java 推荐接入入口、协议类型和内部协作者的 API 与 Javadoc 边界，补齐稳定门面及包级说明，保留必要源码与内部契约说明。

### Fixed

- 编号策略刷新时，主表单和保存入口明确展示等待；读取失败或缺少有效保存策略时在表单正文提示并支持重试，隐藏或只读编号字段同样参与就绪校验，人工与智能体共用保存门禁并保留草稿。
- 独立详情更新从持久化记录保留归属范围，保存回执与翻译任务沿用独立记录上下文；嵌套打开同一模块的其他记录时保留各自身份，后台翻译继续复核实时权限及记录归属。

### Compatibility

- 无新增数据库迁移。记录身份上下文由标准详情入口管理，不能授予权限或切换租户；原有动作、数据范围和字段权限继续执行，显式范围冲突及不透明选择仍按原约束校验。独立详情能力应配套升级前后端。
- 显式生成编号仍等待业务动作，编辑已赋码记录可保留原号；候选不写入草稿，最终编号及占用校验仍以服务端保存结果为准。

## 0.26.21 - 2026-10-22

### Changed

- Maven Central 统一上传完整平台 bundle，保留现有 11 个模块坐标及构件，减少部署次数并排除仓库级元数据与旧版本；增加无凭据用量盘点和正式发布清单验证。
- Maven 上传后的校验、发布及最终等待统一由平台承接，到达 `PUBLISHED` 后再继续 npm 发布；状态和响应体读取失败只重试原部署，保留部署 ID 与用量报告，并提供显式恢复入口。

### Fixed

- 修复静态枚举与表单业务 code 在编码规则中的取值差异，统一预览、规则试算、标准保存、显式取号与流水分桶；不同类型保持独立计数，失败时业务记录、流水与占用整体回滚。
- 标准记录保存被明确拒绝时保留草稿并就地展示主表字段或子表行反馈，草稿修改后清除旧拒绝，迟到响应不会覆盖新草稿；结果未知的保存仍沿用回执核实流程。
- 元数据变更集诊断保留机器标识、原文与参数，由后端统一投影中英文展示资源；人工与助手共用展示入口，未声明或原文、版本不匹配的诊断保持原文。
- 收敛桌面与窄屏租户导航，修复切换租户时的草稿保护及模块页面高度、滚动和操作区交互边界。

### Compatibility

- 无新增数据库迁移。业务编码的 `CodeTitleEnum` 来源使用稳定的 `getCode()`，普通枚举沿用平台公共选项值契约；业务无需补充 Java 枚举名称兼容映射。
- 预览仍不占号，关闭联动改号时修改来源字段保留既有编码，人工编号、重复校验与历史占用契约保持不变。

## 0.26.20 - 2026-10-22

### Added

- 只读工作区复用标准常驻字段、条件编排与排序交互；具名入口沿用菜单与页签恢复链路，保留业务路由映射中的默认展示及查询配置。
- 公开只读业务投影契约及标准工作区，复用编译后的页面描述、列表、详情和自适应布局，无需投影表或可写 CRUD；补齐业务展示组件、解析器及真实安装包消费者验证。
- 静态模块支持多个菜单声明，可分别绑定入口参数、默认 UI 配置和查询模板；各入口保持独立菜单身份，共享模块动作和记录授权。

### Fixed

- 系统菜单默认 UI／查询配置可在租户页面消费，按配置 owner 聚合并保持普通 CRUD 与业务查询的租户隔离。
- 修复视图切换时条件与身份短暂错配、查询能力收缩后残留筛选，以及常驻条件提交绕过最终复杂度校验的问题。
- 引用选择器允许保留历史停用／失效引用，但移除后不能重新选入；补齐跨目录与授权修订变化的契约验收。
- 修复条件合并额外增加根层级的问题，按最终请求校验条件复杂度，避免编辑器合法草稿超出服务端限制。
- 修复路由菜单保存时丢失业务入口参数的问题，支持同一路由承接多个具名视图；入口参数不替代服务端业务资格、动作或数据范围校验。

## 0.26.19 - 2026-10-21

### Added

- 标准业务通知支持通知级持续展示策略，可在详情抽屉、编辑弹窗及多层弹窗打开时保持可见和可操作，复用通知动作与附件能力，并保留当前页面及未保存内容。
- 流程画布支持撤销、重做、全选、复制、粘贴及删除快捷键；复制结构化分支时重建内部引用，对需要重新配置的人工选路节点给出提示。

### Changed

- 模块流程管理改用标准列表抽屉，支持搜索、排序、启停及行操作；新建和设置使用独立抽屉，具体流程在独立画布中编排。
- 流程选择统一按标准列表顺序匹配，保持组织距离、普通流程与兜底流程、租户与全局模板的层级语义；匹配条件复用平台公式编辑与校验能力。
- 流程节点属性在宽屏常驻、窄屏抽屉之间自适应切换并保留编辑状态；画布工具浮动展示，节点类型卡片与画布共享类型配色，分支和汇聚使用简化的菱形节点。

### Fixed

- 修复模块扩展入口在运行态更新后丢失、点击节点重置画布及异步粘贴或删除覆盖较新编辑状态的问题。
- 修复持续通知被普通通知排序或折叠隐藏的问题，保持过期与重复执行保护，以及打开业务目标时的导航和编辑状态。
- 修正节点属性字体、操作区布局及强调色主题契约，保持独立组件与嵌套主题下的展示一致性。

### Compatibility

- 已有 PostgreSQL 数据库升级前应停止应用、备份数据，依次执行 `scripts/migrations/workflow-definition-optional-alias-postgresql.sql` 和 `scripts/migrations/workflow-selection-order-postgresql.sql`。脚本适用于 `public` schema，保留已有流程别名，并将旧优先级转换为各租户、模块分区内的列表顺序；原同优先级流程升级后应复核顺序。
- 流程内部身份统一使用记录 ID，`alias` 成为可选兼容接入键；非审批流程仍必须显式配置模块动作编码 `actionCode`，且首次发布后不可修改。旧的未发布非审批草稿可通过设置补齐动作编码。
- 通知默认继续在抽屉或弹窗打开时隐藏，持续可见须由通知显式声明；通知展示策略不改变动作权限、有效期及业务执行契约。

## 0.26.18 - 2026-10-21

### Added

- 交付动静统一业务编码能力，静态模型通过 `@BusinessCode` 与 `CodeAbility` 声明接入，动态业务通过模块字段配置接入，共享预览、发号、占用及回收生命周期。
