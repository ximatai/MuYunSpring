# UI 页面编排专项治理（临时）

> 状态：临时专项记录。本文用于约束动态模块页面编排的首期交付，并在模型、运行态和正式专题文档稳定后删除；不作为长期并行架构说明。

## 目标与边界

动态模块的页面编排不是字段表格配置，而是受模板约束的页面组合：元数据提供可用字段事实，设计器维护 UI Tree，运行态将**已发布**的页面方案编译为统一 UI descriptor 与执行计划。

```text
已发布主元数据与能力
    -> 页面定义 / 界面方案 / 修订
    -> 已发布的页面 UI Tree
    -> ModuleUiDefinition / ResolvedModuleUiDescriptor / ModuleExecutionPlan
    -> 动态记录页面与读写运行态
```

静态声明和动态页面编排仍须归一到同一 Web 运行时模型。页面配置不得绕过元数据字段事实、数据权限、租户范围、动作授权或后端读写计划；旧“UI 配置集 / UI 配置”仅是兼容读取来源，不再扩展其语义。

## 规范模型

页面编排以三类业务对象表达；修订是界面方案的版本与发布实现细节，不额外形成第四种用户心智对象。

### 页面定义

`页面定义`是模块内稳定的页面身份，包含页面 alias、页面契约类型及主元数据关系锚点。菜单、动作和外部入口应指向页面定义，而不直接绑定某个客户端、模板、租户或组织差异。

首期动态运行态只识别每个模块的 `management` 页面定义。

### 界面方案

`界面方案`（presentation variant）是某个页面定义在特定客户端与作用范围下的一份完整 UI 声明。它归属页面定义，声明目标客户端、作用范围和后续修订来源；不采用字段级继承或 patch 合并。

完整方案使草稿、预览、发布和回滚的结果可确定。租户或组织差异若后续需要，应复制为完整方案后独立维护、独立发布。

### UI 模板与修订

UI 模板是平台维护、版本化的页面语法：固定根节点、插槽、允许的组件节点、属性 schema、校验规则和预览出口。业务方案只能在合法插槽内新增、投放、移动或配置节点，不能删除模板根节点或必备插槽。

`修订`保存某个界面方案的完整 UI Tree、状态和版本。编辑只改草稿；发布通过校验后切换已发布修订，并由发布协调器在事务提交后刷新动态模块的运行态。

## 当前首期实现

首期已经交付并仅承诺以下路径：

1. 页面定义、界面方案、草稿修订和发布修订已具备持久化与发布领域模型。
2. 页面编排工作台可为动态模块初始化 `management` 页面，维护 Web 全局方案的草稿，保存并发布；发布后自动保留一份后续草稿，支持继续编辑。
3. 首个模板为 `management v1`，只有两个可编排插槽：**列表展示字段**与**详情 / 表单字段**。工作台提供元数据字段来源、真实 Tree 组件承载的 UI Tree、跨 Tree 字段投放、列表/详情/卡片预览及组件配置抽屉；卡片复用列表字段，不建立第三份字段配置。
4. 动态运行态优先解析 `management` 的**全局 WEB 已发布修订**，编译为统一的 `ModuleUiDefinition`、descriptor 与执行计划；没有新页面时才回退读取旧 UI 配置快照。
5. 动态记录查询已可消费上述页面编排执行计划，不再要求旧 `uiConfigId`。服务启动时会恢复已发布且拥有主元数据的动态模块运行态。

因此，首期有效的运行时选择可以明确写为：

```text
动态模块 + management 页面定义 + WEB + GLOBAL
    -> 已发布修订
    -> 统一页面 descriptor 与执行计划
```

## 元数据 Tree 的既定边界

左侧元数据 Tree 只提供字段和关系来源，不是 UI 配置本身。投放到 UI Tree 时应绑定稳定的模块元数据字段及其页面角色，不复制字段定义、数据库列或 SQL。

当前工作台已展示主元数据字段。下列目标已达成设计共识，但**尚未交付**：

- 子元数据作为主元数据关系节点展示；
- 单值引用字段（当前记录仅保存一个目标 ID，例如一对一、多对一）按需懒加载目标元数据；
- 单值引用的递归展开、权限与可达性校验、循环检测及最大深度限制。

集合关系、一对多和多对多不作为字段 Tree 的递归展开入口。

## 编辑、预览与发布契约

页面方案遵循以下生命周期：

1. 初始化页面与全局 Web 方案，生成模板根节点和默认插槽。
2. 用户从元数据 Tree 投放字段，或在模板允许的插槽内新增、移动、配置组件节点。
3. 保存仅保存草稿；预览和 UI Tree 使用同一份草稿状态。
4. 发布校验模板规则、插槽、字段可用性、版本冲突和作用范围唯一性。
5. 发布成功后，事务提交后刷新运行态；失败时不得切换已发布修订或留下半生效状态。

首期预览使用结构与示例数据，不直接修改真实业务记录。若后续接入真实数据预览，必须复用运行态权限、数据范围与脱敏策略。

## 明确不做

- 不支持任意自定义模板、任意 UI JSON 或业务端自由定义节点语法。
- 不支持租户/组织方案对全局方案的字段级 patch 合并。
- UI Tree 不直接绑定原始数据库列或 SQL。
- 预览、配置和发布不绕过元数据发布、运行态刷新、权限或数据范围治理。
