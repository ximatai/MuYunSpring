# 导入导出

导入导出面向动态模块交换能力，提供模板、解析、执行、错误文件和数据导出闭环。当前只承诺开启 `EXCHANGE` 能力的动态主实体。

## 能力范围

- 模板可根据当前运行态动态模块字段与关系配置生成工作簿。
- 引用字段可生成辅助下拉，也可按字段关闭。
- 导入支持引用 title 反推。
- 导出支持引用 title 输出。
- 导出支持全量查询上下文和选中记录两种入口。
- 支持一层主子结构的子表导出。
- 导入错误可生成错误文件，并通过 token 下载；错误文件保留出错主子组的完整数据，修正后可直接重传。
- Web 暴露面按 `EXCHANGE` 能力门控。

## 业务使用口径

模板归属于导入能力，用于指导用户准备导入文件。模板中的引用下拉只是辅助输入；即使关闭下拉，导入仍应支持 title 反推。

导入执行区分解析和写入：解析用于提前识别文件结构与可选匹配字段，执行才进入动态记录写链路。执行结果返回新增、更新、跳过、错误数量和错误文件信息。

开启 `EXCHANGE` 的动态模块标准列表页提供导入和当前查询导出工具，按现有动作权限开放。导入先上传解析并核对各表匹配字段与重复策略，再显式确认写入；解析只检查文件结构和可选匹配字段，不承诺完整数据校验。导入后展示总量和各实体新增、更新、跳过及异常项数，成功写入会刷新列表。当前查询导出复用最近一次成功列表请求的全部条件，并去除分页，不将当前页误作全部结果。

工作簿数据以技术字段名定位，展示标题允许同名，不参与原值或错误行的身份判定。错误文件中的 `errorReason` 是平台说明列，不参与业务写入或匹配。错误文件包含出错组的父行和同组子行，可能含已经成功的记录；重试时各表选择 `SKIP` 保留已有记录，仅在明确需要修正已有值时选择 `OVERWRITE`。主表未成功时，子表返回未执行诊断。可收集的数据异常允许部分成功；未处理的写入异常仍由标准事务回滚整次导入，不把失败写入计作成功。当前结果与下载 token 不构成持久化批次流水。

导出复用动态查询上下文，可接收分页、排序、查询模板、外部查询值、快速搜索和手工条件。查询、快速搜索和排序沿用动态页面查询的 SQL 字段边界：虚拟字段不参与导出查询、quickSearch 或排序。选中导出只是追加记录 ID 条件，仍走标准导出动作、数据范围和租户链路。

用户级导出字段、列宽、排序等个人化设置优先由页面偏好承载；只有出现可共享、可发布的系统级导出模板时，才单独抽象模板模型。

## 时间交换口径

工作簿 meta 中的 `timeZone` 用于解释无时区的本地日期时间，必须是 IANA `ZoneId`，例如 `Asia/Shanghai`，不接受 `+08:00`、`GMT+08:00`、`UTC+08:00` 这类 fixed-offset 写法。

动态时间字段按运行态字段语义处理：

- `DATE` 按业务日期导入导出，不做时区换算。
- `TIMESTAMP` 可导入 UTC instant，也可导入工作簿 `timeZone` 下的本地日期时间并转换为 UTC instant。
- `ZONED_TIMESTAMP` 模板会同时输出 owner 列和 companion timeZone 列；导入时两列必须同时提供，owner 值按 companion IANA `ZoneId` 转成 UTC instant。
