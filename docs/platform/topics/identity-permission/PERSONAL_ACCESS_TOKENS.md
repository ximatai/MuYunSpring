# 个人访问密钥

个人访问密钥（Personal Access Token，PAT）供本机工具、脚本及运维自动化代表本人调用平台现有 HTTP API。密钥只绑定创建者用户，不绑定业务目标租户，不维护独立角色、权限快照或租户清单。创建由 `iam.personal_access_token.create` 动作权限控制，沿用平台角色授权；超级管理员默认放行，租户管理员沿用平台已有隐式授权。普通用户获授权后也可创建。

## 模块与入口

密钥管理使用独立静态模块 `iam.personal_access_token`，动作权限及管理审计统一归属该模块。声明 `query`（查看本人）、`create`（创建）、`revoke`（撤销）和 `delete`（删除）动作；创建按角色授权，其余自助清理动作要求本人有效登录会话。模块不挂载平台导航菜单，不发布通用 CRUD 或字段编辑接口，页面仍由右上角账号菜单中的独立弹窗承载。HTTP 管理路径保持 `/iam.auth/access-tokens`。

## 管理与生命周期

工作台右上角账号菜单中的「个人访问密钥」提供独立管理入口，仅在用户拥有创建权限时展示。打开菜单及进入管理时重新检查权限。每个工具或安装环境宜使用独立密钥，便于识别和单独撤销。

- 创建权限仅控制签发新密钥；收回该权限不撤销已有密钥。用户仍可通过本人管理接口查看、撤销密钥及删除已撤销密钥；界面入口随创建权限隐藏。工具调用继续校验用户最新业务权限。申请只检查本人权限，不借用代办主体的权限。
- 创建必须使用本人有效的正常登录会话，并具备创建动作权限；不额外限制距离登录的时间。密钥不能创建或管理其他密钥，不能自行续期。
- 名称为 1—100 字符，有效期为 1—365 天，界面默认 90 天。不采用闲置滑动续期。
- 完整密钥只在创建成功响应中返回一次；关闭弹窗或检测到登录会话变化时清除明文展示。列表只返回 ID、名称、展示前缀、创建/到期/撤销时间及最近使用时间，不返回密钥或摘要。最近使用时间最多每分钟写入一次，不作为精确审计流水。
- 每个用户只管理自己的密钥；撤销、删除均为幂等操作，其他用户或不存在的 ID 不产生修改。
- 只有已撤销的密钥可以删除，已过期但未撤销的密钥也须先撤销。删除使用标准软删除字段，从管理列表移除，保留密钥记录及审计；不提供恢复入口。删除后认证仍拒绝，返回 `ACCESS_TOKEN_INVALID`。
- 普通浏览器登出、会话过期、会话强制下线和正常修改本人密码不撤销密钥。
- 账号停用、删除、管理员修改或重置密码时永久撤销已有密钥。重新启用、恢复账号不恢复旧密钥。
- 每次认证检查密钥状态及用户最新有效状态，随后使用现有动作授权、数据范围和业务约束，不保留签发时的权限快照。
- 租户用户继续使用本人所属租户身份；租户停用期间认证拒绝，重新启用后未撤销且未过期的密钥可继续使用。租户状态检查不为密钥增加独立租户授权。
- 撤销后新的认证请求立即拒绝；已经认证并开始执行的请求可以完成原事务，不保证中断在途业务。

密钥替换使用「创建新密钥 → 更新工具配置并验证 → 撤销旧密钥」。到期不提供自动刷新。若创建响应因网络中断丢失，不能取回明文；应查看列表确认并撤销无法使用的密钥，再重新创建。

## HTTP 管理协议

以下路径相对于 API context path（默认 `/api`）。管理操作使用浏览器登录会话的 `Authorization: Bearer <session-token>`，不需要目标租户；即使请求包含业务租户头，密钥仍只属于用户，存储在平台范围。

| 方法 | URL | 请求/响应 |
| --- | --- | --- |
| GET | `/iam.auth/access-tokens/capabilities` | 返回 `{ "canCreate": true/false }`，与实际创建共用动作权限判断，无需用户管理模块的查询或查看权限。 |
| GET | `/iam.auth/access-tokens` | 本人密钥元信息数组，包含已撤销和已到期记录。 |
| POST | `/iam.auth/access-tokens` | 请求 `{"name":"USB 配装工具","validDays":90}`；响应 `{"token":"…","accessToken":{…元信息…}}`。 |
| POST | `/iam.auth/access-tokens/{id}/revoke` | 撤销本人密钥，无响应正文。 |
| DELETE | `/iam.auth/access-tokens/{id}` | 删除本人已撤销的密钥，无响应正文；未撤销返回 `400 VALIDATION_FAILED`。 |

管理响应使用 `Cache-Control: no-store`。请求不能指定密钥所有者、授权范围或租户清单。

## 工具调用

```http
Authorization: Bearer muyun_pat_<secret>
X-MuYun-Tenant-Id: <本次业务操作的目标租户>
```

密钥采用带 `muyun_pat_` 前缀的随机秘密；服务端仅保存 SHA-256 摘要。工具必须通过 HTTPS 发送认证头，不将密钥放在 URL、普通配置输出、日志或诊断报告中；本机优先使用操作系统凭据管理器，不保存管理员账号密码。密钥只用于工具访问平台，不能下发到安全帽 APK、设备配置或设备自身的上线认证中。

工具直接调用原有静态或动态模块 API，不另建外部直写入口。目标租户属于本次业务请求上下文，由平台现有租户校验负责。平台级用户可按现有权限先后为不同租户操作；普通租户用户仍受原有租户边界约束，不能凭密钥跨租户。安全帽注册等确有租户归属要求的接口仍负责校验目标租户；PAT 不改变业务层对租户的要求。

## 错误与续办

认证失败使用平台标准 JSON 错误响应，包含 `code`、HTTP `status` 和 `traceId`。只有秘密匹配到存储记录后，才返回该密钥的详细失效原因。

| HTTP | code | 工具处理 |
| --- | --- | --- |
| 401 | `ACCESS_TOKEN_INVALID` | 格式错误或秘密不匹配；检查配置。 |
| 401 | `ACCESS_TOKEN_EXPIRED` | 到期，暂停并更新凭据。 |
| 401 | `ACCESS_TOKEN_REVOKED` | 已撤销，暂停并更新凭据。 |
| 401 | `ACCESS_TOKEN_OWNER_UNAVAILABLE` | 所属用户不可用，联系管理员。 |
| 403 | `ACCESS_DENIED` / `TENANT_ACCESS_DENIED` | 身份有效，但管理权限或目标租户校验拒绝；更换密钥不能扩大权限。 |

工具应按错误码处理，不依赖显示语言或错误文案。认证失效应暂停平台操作、保留本地进度；更新凭据后先核对平台持久化状态，再决定续办。注册、取号等写操作不能因网络错误或凭据替换而盲目重放，查重、硬件身份与业务幂等仍由对应接口契约负责。

## 审计与边界

创建、实际撤销和实际删除在 IAM 领域产生轻量审计事实，记录操作者及目标密钥 ID；工具调用的静态业务日志和动态运行审计记录认证方式及非秘密凭据 ID，并保留真实用户和业务目标租户。事件捕获时保存认证来源，延迟落库不重新读取请求上下文。日志不保存秘密、摘要或完整认证头。

PAT 是个人凭据，不是安全帽设备凭据，也不是独立应用身份。当前不建设 Key 专属租户授权、Key 专属角色或 OAuth 授权中心；后续出现独立机器主体或第三方委托场景时另行设计。
