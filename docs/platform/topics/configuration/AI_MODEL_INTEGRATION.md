# 模型连接配置

## 能力定位

首期模型能力只解决受治理的模型连接与文本调用：平台维护一条全局 OpenAI-compatible 模型连接，每个租户至多维护一条租户级连接；业务代码通过 `AiModelGateway` 使用当前有效连接。它不包含智能体身份、工具调用、菜单代办、单据修改、元数据编排、会话记忆或模型路由。

静态与动态业务未来都只能通过来源无关的 `AiModelGateway` 访问模型；不得在 Controller、动态执行器或业务 Service 中直接持有供应商 SDK、API Key 或供应商 URL。

## 供应商目录

`AiModelProvider` 是平台级供应商目录，仅平台超级管理员可维护。供应商定义稳定编码、名称、启停状态、协议和 API 基础地址；首期预置 DeepSeek、阿里云百炼和 LM Studio。租户只能从启用的供应商中选择，不能新增供应商或修改其地址。

首期协议固定为 `OPENAI_COMPATIBLE`。基础地址只接受 HTTPS；本机回环地址允许 HTTP 以支持 LM Studio。地址不接受账号信息、查询参数或片段，HTTP 客户端不跟随重定向。供应商配置是受治理的端点目录，不是任意 HTTP 请求或供应商脚本机制；供应商特有参数、模型自动发现、协议插件和降级策略不属于当前契约。

## 配置、可见范围与优先级

`AiModelConfiguration` 只有两种归属，并且每种归属最多一条记录：

1. `全局级`：`tenantId` 为空，仅系统管理员可创建和维护，对全部租户生效。
2. `租户级`：`tenantId` 为目标租户。系统管理员可代建并绑定任意租户；租户管理员创建时服务端强制绑定当前租户，不能伪造其他租户。

平台管理员与目标租户拥有相应权限的管理员编辑同一条租户级记录，不存在管理员配置与租户自建配置并列或互相覆盖。当前租户优先使用自己的租户级配置；不存在时回退全局级配置。没有可用配置时返回 `CONFIG_MISSING`。

不支持“指定租户”子表或多租户授权语义。配置归属只由 `tenantId` 表达，运行时和页面均不解析或展示其他租户范围模型。

## 凭据保护

API Key 是写入专用字段：读取 API、模块描述符、OpenAPI 和运行审计都不返回其值，只返回非敏感的 `apiKeyConfigured` 状态。更新时不传 Key 保留原值，传入非空值替换原值。保留凭据通过字段保护能力从 RAW 更新快照中解密并验签，普通编辑和启停仍走同一持久化保护链，不能把存储密文当作业务明文再次加密。

凭据持久化复用平台字段保护能力：写入时以 AES-GCM 加密并以 HMAC-SHA-256 生成完整性签名，读取时先解密再校验签名。生产环境必须通过部署密钥提供 Base64 编码的 16、24 或 32 字节主密钥：

```yaml
muyun:
  security:
    field-protection:
      key-base64: ${MUYUN_SECURITY_FIELD_PROTECTION_KEY_BASE64}
```

缺少该配置时，平台不允许持久化受保护的模型凭据。密钥本身不进入数据库、日志、审计或配置导出。后续如迁移到 Vault/KMS，应替换密钥提供器，不改变模型配置或调用门面。

## 调用与诊断

`AiModelGateway` 当前提供普通文本生成和 SSE 流式文本输出。适配器使用 OpenAI chat-completions 协议，统一映射消息、温度和最大输出 token；服务端不保存对话内容。SSE 以 `[DONE]` 表示正常完成，供应商错误事件、非法事件和提前断流均抛出平台异常，不暴露供应商错误报文；已交付的部分文本不代表调用成功。

`POST /platform.ai_model_configuration/{id}/test` 是持有配置更新权限的连通性诊断。它发送固定的最小探测请求，只返回连通状态与耗时，不返回模型文本、完整供应商响应或凭据。

本地 LM Studio 可用于集成验证，使用 `LM_STUDIO_KEY` 作为请求凭据；测试或运行日志不得输出该环境变量。
